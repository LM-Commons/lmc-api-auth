LmcApiAuthentication offers API tools to authenticate requests

## Requirements

- PHP 8.3 or higher

## Installation

LmcApiAuthentication only officially supports installation through Composer.

Install the module:

```sh
$ composer require lm-commons/lmc-api-auth
```

You will be prompted by the Laminas Component Installer plugin to inject the
component into your `config/config.php` file.
